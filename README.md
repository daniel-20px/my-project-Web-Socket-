# 🎬 CineDebate - Chat em Tempo Real

Um sistema de chat desenvolvido para debates em tempo real, utilizando **Node.js**, **TypeScript** (com suporte nativo via Node 24) e **Socket.io**.

## 🚀 Teste Agora Mesmo
O projeto está hospedado e pronto para uso na nuvem:
👉 [Acesse o CineDebate ao Vivo aqui](https://onrender.com)

## 🛠️ Tecnologias Utilizadas
- **Node.js** (v24 com `--experimental-strip-types`)
- **TypeScript**
- **Express**
- **Socket.io** (WebSockets)
- HTML5 / CSS3 / JavaScript (Vanilla)

## 💻 Como Rodar Localmente

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor em ambiente de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Acesse no seu navegador: `http://localhost:2000`
